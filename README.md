🛡️ Portfolio Profesional - Lic. Ahmed O. Alfonso Garcia

📖 Descripción

Portfolio profesional con estética de terminal Linux, diseñado para mostrar mi experiencia en Ciberseguridad, Hacking Ético y Auditoría de Seguridad. Totalmente responsive, multilingüe y con formulario de contacto seguro integrado.

✨ Características Principales

- 🖥️ **Diseño Terminal**: Estética inspirada en consola Linux con scanlines y prompts
- 🌍 **Multilingüe**: 5 idiomas (Español, Inglés, Alemán, Italiano, Francés)
- 📱 **Responsive**: Adaptado a móviles, tablets y escritorio
- 🔒 **Formulario Seguro**: Integración con Formspree (sin exponer email)
- 🚀 **Proyectos Destacados**: 4 herramientas de ciberseguridad documentadas
- ⚡ **Carga Rápida**: Sin dependencias externas, HTML/CSS/JS puro
- ♿ **Accesible**: Etiquetas ARIA y navegación por teclado

🛠️ Tecnologías Utilizadas

| Tecnología | Uso |
|------------|-----|
| **HTML5** | Estructura semántica |
| **CSS3** | Estilos, animaciones, responsive design |
| **JavaScript (Vanilla)** | Sistema de traducción, formulario AJAX |
| **Formspree** | Backend seguro para formulario de contacto |
| **Google Fonts** | Fuentes JetBrains Mono y Fira Code |

Funcionamiento del Sistema de Traducción

- **Detección automática**: Detecta el idioma del navegador al cargar
- **Persistencia**: Guarda la preferencia en `localStorage`
- **Selector visual**: Botones en la barra superior del terminal
- **Traducción completa**: Perfil, experiencia, proyectos, formulario y placeholders
